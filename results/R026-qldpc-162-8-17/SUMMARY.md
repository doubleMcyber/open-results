A [[162,8,17]] two-block group-algebra code with checks of weight 7. Let C27 x C3 be generated by x and y, and take A = 1 + x + x^5 and B = 1 + xy + x^4 y^2 + x^15 y. The CSS code with H_X = (A | B) and H_Z = (B^T | A^T), where A and B stand for their 81 x 81 multiplication matrices, has 162 qubits, 8 logical qubits and distance 17. Every check has weight 7, and each qubit lies in 3 or 4 checks of each type. So k d^2 / n = 14.27.

The comparison value is 13.71. It comes from a table of published CSS codes frozen on 2026-11-24, with published distances taken at face value, and is the largest k d^2 / n in that table at check weight at most 7 and length at most 162. A [[126,12,12]] code sets it. At length exactly 162, the best published weight-7 code found in the sources used here is [[162,8,15]] (11.11).

A published weight-7 code at length 168, [[168,12,15]], scores 16.07, higher than this one. At length 162 and below, listed CSS codes with check weight 8 or 9 score higher, and so does a listed non-CSS code of weight 7 whose distance is only an upper bound.

The distance is exact for both error types. Witnesses of weight 17 give the upper bound, and `verify.py` checks them with the standard library. The lower bound, that no logical operator of weight 16 or less exists, rests on exhaustive computer searches. It has no compact certificate and `verify.py` does not recheck it.

This entry claims nothing about circuit-level performance, decoders, thresholds or hardware layout. It does not beat IBM's [[144,12,12]] gross code in general. The new code's k d^2 / n is higher than the gross code's 12, but it needs checks of weight 7 instead of 6, uses more qubits and encodes 8 logical qubits instead of 12.
